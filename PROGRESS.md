## Требует внимания

- React изучается с начального уровня: сначала теория и разбор кода, затем
  маленькая практика. Не предполагать знание React по прошлым кратким беседам.
- Перевести знакомую Vue-модель на React, не механически копируя аналоги.
- Укреплять HTML/CSS параллельно с React.
- Позже отдельно отработать Git, SCSS, Styled Components, тесты, code review и
  современные браузеры — это требования целевой вакансии.

## Следующее действие

1. Пользователь самостоятельно пишет компоненты `TodoList` и `TodoItem` для
   заданного массива задач.
2. Проверить понимание props, `map`, `key` и различия между вызовом функции и
   использованием компонента в JSX.
3. После проверки создать Vite-приложение в `D:\react` и перенести туда код.
