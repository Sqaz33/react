## Требует внимания

- React изучается с начального уровня: сначала теория и разбор кода, затем
  маленькая практика. Не предполагать знание React по прошлым кратким беседам.
- Перевести знакомую Vue-модель на React, не механически копируя аналоги.
- Укреплять HTML/CSS параллельно с React.
- Позже отдельно отработать Git, SCSS, Styled Components, тесты, code review и
  современные браузеры — это требования целевой вакансии.

## Следующее действие

1. Не выдавать новое задание. Пользователь продолжает первоначальное задание:
   статический Todo из `TodoHeader`, `TodoForm`, `TodoList` и `TodoItem`.
2. До продолжения практики объяснить весь необходимый синтаксис: объявление,
   import/export, JSX, props, `map` и `key`.
3. После того как пользователь закончит первоначальное задание, проверить его
   существующие файлы и только потом переходить дальше.
