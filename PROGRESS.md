## Требует внимания

- Команды npm нужно выполнять в каталоге, содержащем `package.json` — сейчас это
  `D:\react\react`, а не `D:\react`.
- `key` является специальным атрибутом React и не передаётся компоненту через
  props; `TodoItem` не должен принимать `{ key, item }` и ставить этот `key` на
  внутренний `<li>`.
- `main.jsx` импортирует отсутствующий `src/index.css`.
- React изучается с начального уровня: сначала теория и разбор кода, затем
  маленькая практика. Не предполагать знание React по прошлым кратким беседам.
- Перевести знакомую Vue-модель на React, не механически копируя аналоги.
- Укреплять HTML/CSS параллельно с React.
- Позже отдельно отработать Git, SCSS, Styled Components, тесты, code review и
  современные браузеры — это требования целевой вакансии.

## Следующее действие

1. Пользователь исправляет импорт отсутствующего `index.css`: восстанавливает
   файл или удаляет импорт до начала работы над стилями.
2. Исправляет `TodoItem`, чтобы компонент принимал только `item`, а `key`
   оставался на `<TodoItem>` внутри `map`.
3. Доводит первоначальные требования: `TodoForm` содержит форму, поле и кнопку,
   а выполненная задача отображается зачёркнутой.
4. Запускает `npm run dev` из `D:\react\react`; после этого повторно проверить
   сборку и завершить review первоначального задания.
