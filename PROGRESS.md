## Проверено и освоено в этом репозитории

- Самостоятельно создан Vite-проект React с JavaScript.
- Самостоятельно объявлены и подключены `TodoHeader`, `TodoForm`, `TodoList` и
  `TodoItem`.
- `App` передаёт массив задач в `TodoList`, а список создаётся через `map`.
- Исправлено понимание специального атрибута `key`: он остаётся на `TodoItem` в
  родительском списке и не извлекается из props внутри `TodoItem`.
- Выполненные задачи отображаются через условный `className` и CSS-класс.
- Статический `TodoForm` содержит форму, поле и кнопку.
- Линтер и production-сборка проходят успешно.
- `TodoForm` самостоятельно переведён на локальный state через `useState`.
- Поле связано со state через `value` и `onChange`; счётчик символов подтверждает
  ререндер после `setTitle`.
- На практике использован JSX-фрагмент без лишнего DOM-контейнера.
- Массив `todos` переведён в state общего родителя `App`.
- `TodoForm` сообщает о добавлении через callback-prop `onAddTodo`.
- Новая задача добавляется функциональным setter без мутации старого массива.
- Отправка формы работает через `onSubmit`, `preventDefault`, валидацию и очистку
  controlled input.

## Требует внимания

- Помнить: команды npm выполняются в каталоге `D:\react\react`, где находится
  `package.json`.
- React изучается с начального уровня: сначала теория и разбор кода, затем
  маленькая практика. Не предполагать знание React по прошлым кратким беседам.
- Перевести знакомую Vue-модель на React, не механически копируя аналоги.
- Укреплять HTML/CSS параллельно с React.
- Позже отдельно отработать Git, SCSS, Styled Components, тесты, code review и
  современные браузеры — это требования целевой вакансии.

## Следующее действие

Пользователь создаёт в `App` функцию переключения задачи по `id`, обновляет
массив функциональным setter и `map`, копирует только найденный объект через
object spread и меняет его `completed`. Callback передаётся через `TodoList` в
`TodoItem`, где управляемый checkbox вызывает его с `item.id`.
