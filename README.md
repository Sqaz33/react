# React Internship Training

Учебный репозиторий для подготовки к стажировке Frontend React в МТС Веб
Сервисы.

Основные документы:

- `LEARNING_PLAN.md` — полная программа подготовки;
- `PROGRESS.md` — текущий этап и журнал занятий;
- `STUDENT_CONTEXT.md` — исходная база и предпочтительный формат обучения;
- `AGENTS.md` — правила ведения занятий и обновления прогресса.

Код учебного Task Board будет развиваться в этом же репозитории.
