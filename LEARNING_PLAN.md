# План подготовки к стажировке Frontend React

## Целевая позиция

«Стажёр Frontend React разработчик, AoS B2B, МТС Веб Сервисы».

Требования и рабочие задачи, которые покрывает программа:

- разработка и развитие интерфейсов на React;
- JavaScript, HTML5 и CSS;
- SCSS и Styled Components;
- Git и командная работа;
- современные браузеры и DevTools;
- анализ, проектирование и оценка технических решений;
- unit- и функциональные тесты;
- участие в code review.

## Итоговый учебный проект

Todo постепенно развивается в `Task Board` для небольшой B2B-команды:

- создание, редактирование, выполнение и удаление задач;
- статусы, приоритеты, поиск, фильтры и сортировка;
- несколько страниц и URL-состояние;
- сохранение и REST API;
- состояния загрузки, ошибки и пустые состояния;
- адаптивная и доступная вёрстка;
- тесты;
- командный Git-процесс и code review.

## Критерий готовности

Пользователь готов к техническому отбору, когда может без копирования готового
решения:

1. Разбить интерфейс на компоненты и объяснить границы компонентов.
2. Выбрать минимальное состояние и правильно разместить его в дереве.
3. Реализовать CRUD и формы с валидацией.
4. Выполнить REST-запрос и обработать loading/error/empty/success.
5. Объяснить рендер, props, state, `key`, хуки и правила хуков.
6. Написать и объяснить unit/компонентные и функциональные тесты.
7. Сверстать адаптивный и семантический интерфейс.
8. Использовать Git-ветку, осмысленные коммиты и провести code review.
9. Найти типичную проблему через DevTools и объяснить браузерное поведение.
10. За ограниченное время выполнить небольшую React-задачу и защитить решения.
