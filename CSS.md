# CSS: учебник и шпаргалка

CSS — Cascading Style Sheets, «каскадные таблицы стилей». CSS отвечает за
внешний вид и раскладку HTML-элементов.

Этот файл устроен как справочник: сначала короткая теория, затем таблицы
значений и небольшие примеры. Его не нужно читать целиком перед каждой задачей.
Нужный раздел можно найти по оглавлению.

## Главное различие: свойство, значение и атрибут

~~~css
.todo-list {
  display: flex;
  justify-content: center;
}
~~~

| Часть | Пример | Что это |
|---|---|---|
| селектор | .todo-list | выбирает элементы |
| свойство | justify-content | что именно настраиваем |
| значение | center | как настраиваем |
| объявление | justify-content: center; | свойство вместе со значением |
| правило | весь блок с фигурными скобками | селектор и объявления |

justify-content — не HTML-атрибут, а CSS-свойство. center — одно из его
значений. HTML-атрибуты записываются в открывающем теге: id, disabled, href,
aria-label. В JSX большинство атрибутов выглядит так же, но class записывается
как className.

## 1. Подключение CSS и базовый синтаксис

В React-проекте Vite таблицу стилей обычно импортируют из JavaScript:

~~~jsx
import "./styles/index.scss";

export function TodoItem() {
  return <li className="todo-item">Задача</li>;
}
~~~

CSS ищет в итоговом DOM элемент с соответствующим классом:

~~~css
.todo-item {
  padding: 8px;
}
~~~

### Универсальные значения

Их можно назначить почти любому CSS-свойству.

| Значение | Смысл |
|---|---|
| inherit | взять вычисленное значение у родителя |
| initial | взять начальное значение из стандарта CSS |
| unset | для наследуемого свойства работает как inherit, иначе как initial |
| revert | откатиться к правилу предыдущего источника, часто к стилям браузера |

inherit не означает «скопировать все стили родителя». Оно применяется только к
конкретному свойству:

~~~css
.todo-link {
  color: inherit;
}
~~~

## 2. Единицы измерения и цвета

### Единицы длины

| Единица | От чего считается | Когда полезна |
|---|---|---|
| px | CSS-пиксель | рамки, небольшие отступы, точные размеры |
| % | размер содержащего блока или значение родителя; зависит от свойства | относительная ширина |
| em | текущий font-size элемента | размеры, связанные с текстом компонента |
| rem | font-size корневого html | единый масштаб текста и отступов |
| vw | 1% ширины viewport | размеры от ширины окна |
| vh | 1% высоты viewport | размеры от высоты окна |
| dvh | 1% динамической высоты viewport | полноэкранные блоки на мобильных |
| ch | примерная ширина символа 0 текущего шрифта | удобная длина строки |
| fr | доля свободного места в Grid | колонки и строки Grid |

rem обычно предсказуемее em: вложенность элементов не перемножает размер.

~~~css
.page {
  width: min(100%, 70rem);
  min-height: 100dvh;
  padding-inline: 1rem;
}
~~~

### Цвета

| Формат | Пример | Особенность |
|---|---|---|
| ключевое слово | red | готовое имя цвета |
| HEX | #1f2937 | красный, зелёный и синий в шестнадцатеричной записи |
| короткий HEX | #fff | сокращение #ffffff |
| rgb | rgb(31 41 55) | каналы RGB |
| rgb с прозрачностью | rgb(31 41 55 / 60%) | альфа-канал |
| hsl | hsl(220 15% 20%) | тон, насыщенность, светлота |
| transparent | transparent | полностью прозрачный цвет |
| currentColor | currentColor | текущее вычисленное значение color |

currentColor удобен для рамок и иконок, которые должны иметь цвет текста.

## 3. Селекторы и комбинаторы

### Основные селекторы

| Селектор | Что выбирает |
|---|---|
| * | все элементы |
| button | все элементы button |
| .todo-item | элементы с классом todo-item |
| #app | элемент с id app |
| [disabled] | элементы с атрибутом disabled |
| [type="search"] | элементы с точным значением атрибута |
| [class^="todo-"] | значение атрибута начинается с todo- |
| [class*="active"] | значение атрибута содержит active |

### Комбинирование

| Селектор | Смысл |
|---|---|
| .a.b | один элемент одновременно имеет классы a и b |
| .a .b | элемент .b находится где угодно внутри .a |
| .a > .b | .b — непосредственный ребёнок .a |
| .a + .b | .b идёт сразу после .a на том же уровне |
| .a ~ .b | .b идёт после .a на том же уровне, не обязательно сразу |
| .a, .b | применить одно правило и к .a, и к .b |

~~~html
<li class="todo-item completed">
  <span class="todo-title">Задача</span>
</li>
~~~

~~~css
/* Тот же li имеет сразу два класса. */
.todo-item.completed {
  opacity: 0.7;
}

/* span расположен внутри li. */
.todo-item .todo-title {
  text-decoration: line-through;
}
~~~

### Полезные функциональные селекторы

| Селектор | Смысл |
|---|---|
| :not(.active) | элемент, который не подходит под .active |
| :is(h1, h2, h3) | любой из переданных селекторов |
| :where(h1, h2, h3) | как :is, но не увеличивает специфичность |
| :has(> input:checked) | элемент, внутри которого найдено совпадение |

:has уже поддерживается современными браузерами, но перед применением в рабочем
проекте всё равно проверяют требования к версиям браузеров.

## 4. Каскад, специфичность и наследование

Каскад решает, какое объявление победит, если к одному свойству одного элемента
подходят несколько правил.

Упрощённый порядок:

1. источник и важность правила;
2. специфичность селектора;
3. если специфичность равна — правило ниже в коде.

### Специфичность

Она сравнивается по разрядам слева направо, а не простой суммой.

| Разряд | Что добавляет | Пример |
|---|---|---|
| inline | style в HTML/JSX | style={{ color: "red" }} |
| ID | селектор с # | #app |
| class | класс, атрибут, псевдокласс | .item, [disabled], :hover |
| type | тег или псевдоэлемент | button, ::before |

Примеры:

| Селектор | Условная запись |
|---|---|
| button | 0-0-0-1 |
| .button | 0-0-1-0 |
| .todo-actions button | 0-0-1-1 |
| .button.primary | 0-0-2-0 |
| #app .button | 0-1-1-0 |

.button.primary сильнее .todo-actions button, потому что разряд классов 2 против
1. До сравнения тегов дело уже не доходит.

Не следует постоянно повышать специфичность. Предсказуемые классы компонентов
обычно удобнее длинных цепочек и !important.

### Что значит зачёркнутое свойство в DevTools

В панели Styles зачёркнутое объявление чаще всего означает, что оно подошло к
элементу, но проиграло каскад другому объявлению. Незачёркнутое объявление тоже
может не дать видимого эффекта: например, justify-content ничего не распределит,
если у контейнера нет свободного места.

### Наследование

Наследование идёт от родителя к потомку по DOM-дереву. Оно не связано с тем,
как называются классы.

| Обычно наследуются | Обычно не наследуются |
|---|---|
| color | margin |
| font-family | padding |
| font-size | border |
| font-weight | width и height |
| line-height | display |
| text-align | position |
| visibility | background |

Если дочерний элемент имеет собственное правило color, оно заменит
унаследованное значение.

## 5. Box model и box-sizing

Каждый видимый элемент можно представить коробкой:

~~~text
margin → border → padding → content
~~~

| Слой | Что это |
|---|---|
| content | текст или содержимое элемента |
| padding | внутренний отступ между content и border |
| border | рамка |
| margin | внешний отступ от соседей |

### box-sizing

| Значение | Как считается заданная width |
|---|---|
| content-box | только content; padding и border прибавятся |
| border-box | content + padding + border уже входят в width |

Практический глобальный сброс:

~~~css
*,
*::before,
*::after {
  box-sizing: border-box;
}
~~~

::before и ::after указаны отдельно, потому что это отдельные создаваемые CSS
коробки — псевдоэлементы.

### Сокращённая запись margin и padding

| Количество значений | Порядок |
|---|---|
| 1 | все четыре стороны |
| 2 | вертикаль, горизонталь |
| 3 | верх, горизонталь, низ |
| 4 | верх, право, низ, лево — по часовой стрелке |

~~~css
.page {
  margin: 40px auto;
  padding: 8px 16px 24px;
}
~~~

Здесь margin сверху и снизу равен 40px, а auto слева и справа делит свободное
место поровну. Это центрирует блок, только если его ширина меньше ширины
родителя.

Вертикальные margin соседних обычных блочных элементов иногда схлопываются:
вместо суммы остаётся больший отступ. Внутри Flexbox и Grid такого схлопывания
нет. Для расстояния между элементами раскладки обычно удобнее gap.

## 6. Размеры и переполнение

### Свойства размеров

| Свойство | Назначение |
|---|---|
| width, height | предпочтительные ширина и высота |
| min-width, min-height | нижняя граница размера |
| max-width, max-height | верхняя граница размера |
| inline-size | размер вдоль строки; обычно ширина |
| block-size | размер поперёк строк; обычно высота |
| aspect-ratio | желаемое отношение ширины к высоте |

width: 100% занимает доступную ширину содержащего блока. max-width ограничивает
рост, но сам по себе не заставляет элемент занять всю меньшую ширину.

~~~css
.todo-layout {
  width: 100%;
  max-width: 700px;
  margin-inline: auto;
  padding-inline: 16px;
}

.preview {
  aspect-ratio: 16 / 9;
}
~~~

### overflow

| Значение | Поведение |
|---|---|
| visible | содержимое рисуется за границами |
| hidden | лишнее обрезается, полос прокрутки нет |
| auto | полосы прокрутки появляются при необходимости |
| scroll | область прокрутки создаётся всегда |
| clip | содержимое обрезается без прокрутки |

Есть отдельные оси overflow-x и overflow-y.

### Многоточие в одну строку

~~~css
.todo-title {
  min-width: 0;
  overflow: hidden;
  white-space: nowrap;
  text-overflow: ellipsis;
}
~~~

Почему нужны все строки:

- nowrap запрещает перенос;
- overflow скрывает вышедший текст;
- text-overflow рисует многоточие;
- min-width: 0 разрешает Flex/Grid-элементу сжаться меньше естественной ширины
  текста. Без этого он может растолкать соседние кнопки.

### object-fit для изображений и видео

| Значение | Поведение |
|---|---|
| fill | растянуть точно в коробку, возможно исказить пропорции |
| contain | показать целиком, могут остаться пустые поля |
| cover | заполнить коробку, края могут обрезаться |
| none | не масштабировать |
| scale-down | выбрать меньший вариант между none и contain |

## 7. Обычный поток и display

Если position не выводит элемент из потока, браузер размещает элементы в
порядке DOM. Блочные элементы обычно идут сверху вниз, строчные — внутри строки.

### Основные значения display

| Значение | Что происходит |
|---|---|
| block | новая строка, доступная ширина родителя |
| inline | участвует в строке; width и height обычно не управляют размером |
| inline-block | находится в строке, но принимает width и height |
| flex | блочный Flex-контейнер |
| inline-flex | строчный Flex-контейнер |
| grid | блочный Grid-контейнер |
| inline-grid | строчный Grid-контейнер |
| none | элемент не рисуется и не занимает место |
| contents | собственная коробка исчезает, дети участвуют в раскладке выше |

display описывает две вещи: как сам элемент участвует во внешней раскладке и
как он раскладывает непосредственных детей. Например, display: flex делает
элемент блочным снаружи и Flex-контейнером внутри.

React Fragment не создаёт DOM-элемент. Поэтому при замене Fragment на div
меняется структура раскладки: новый div становится одним элементом родительского
Flexbox, а заголовок, абзац и кнопка теперь раскладываются уже внутри div по
обычному потоку.

## 8. Flexbox

Flexbox — одномерная раскладка: элементы распределяются по одной главной оси,
а по второй оси выравниваются.

~~~css
.todo-item {
  display: flex;
}
~~~

После этого .todo-item — Flex-контейнер, а только его непосредственные дети —
Flex-элементы.

### Оси

| flex-direction | Главная ось | Поперечная ось |
|---|---|---|
| row | слева направо | сверху вниз |
| row-reverse | справа налево | сверху вниз |
| column | сверху вниз | слева направо |
| column-reverse | снизу вверх | слева направо |

justify-content всегда работает по главной оси. align-items — по поперечной.
Поэтому их визуальное направление меняется вместе с flex-direction.

### Свойства Flex-контейнера

#### flex-direction

| Значение | Результат |
|---|---|
| row | строка в обычном направлении текста |
| row-reverse | строка в обратном направлении |
| column | колонка сверху вниз |
| column-reverse | колонка снизу вверх |

reverse меняет визуальный порядок, но не порядок DOM и клавиатурной навигации.
Использовать его для смыслового переупорядочивания опасно.

#### flex-wrap

| Значение | Результат |
|---|---|
| nowrap | одна линия, элементы при необходимости сжимаются |
| wrap | разрешён перенос на новые линии |
| wrap-reverse | перенос в обратную сторону поперечной оси |

#### justify-content

Распределяет Flex-элементы по главной оси. Эффект виден, только если на ней есть
свободное место.

| Значение | Распределение |
|---|---|
| flex-start | у начала главной оси |
| flex-end | у конца главной оси |
| center | группа по центру |
| space-between | первый у начала, последний у конца, между ними равные интервалы |
| space-around | вокруг каждого элемента одинаковая зона; по краям половина промежутка |
| space-evenly | все промежутки, включая края, одинаковы |
| start | у логического начала направления текста |
| end | у логического конца направления текста |

#### align-items

Выравнивает все элементы контейнера по поперечной оси.

| Значение | Выравнивание |
|---|---|
| stretch | растянуть auto-размер до размера линии; начальное значение |
| flex-start | у начала поперечной оси |
| flex-end | у конца поперечной оси |
| center | по центру поперечной оси |
| baseline | совместить базовые линии текста |
| start, end | у логического начала или конца |

align-items: center не меняет порядок элементов и не прижимает кнопки вправо. В
строке оно только выравнивает checkbox, текст и кнопки по вертикали.

#### align-content

Распределяет несколько Flex-линий по поперечной оси. Не действует на
однострочный nowrap-контейнер.

| Значение | Поведение |
|---|---|
| normal | обычное поведение, часто похоже на stretch |
| stretch | линии растягиваются |
| flex-start | линии у начала |
| flex-end | линии у конца |
| center | линии в центре |
| space-between | свободное место только между линиями |
| space-around | пространство вокруг линий |
| space-evenly | все промежутки равны |

#### gap

| Свойство | Что задаёт |
|---|---|
| gap | расстояние между строками и колонками |
| row-gap | расстояние между строками |
| column-gap | расстояние между колонками |

gap создаёт промежутки только между элементами, но не по внешним краям
контейнера.

~~~css
.todo-actions {
  display: flex;
  flex-wrap: wrap;
  gap: 8px;
}
~~~

### Свойства Flex-элемента

Эти свойства назначаются непосредственному ребёнку Flex-контейнера.

#### flex-grow, flex-shrink, flex-basis

| Свойство | Смысл | Частое значение |
|---|---|---|
| flex-grow | какую долю свободного места можно получить | 0 или 1 |
| flex-shrink | с какой относительной силой можно сжиматься | 0 или 1 |
| flex-basis | стартовый размер по главной оси перед распределением | auto, 0, длина |

flex-grow работает только со свободным местом. Значения — коэффициенты:
элементы с grow 1 и 2 поделят свободное место примерно как 1 к 2.

#### Сокращение flex

Порядок полной записи: grow, shrink, basis.

| Запись | Практический смысл |
|---|---|
| flex: 1 | расти и сжиматься от basis 0; удобно для равных долей |
| flex: 2 | получить вдвое больше свободного места, чем flex: 1 |
| flex: auto | учитывать естественный размер, затем расти и сжиматься |
| flex: none | не расти и не сжиматься |
| flex: initial | не расти, но разрешить сжатие от auto |
| flex: 0 0 120px | фиксированная стартовая колонка 120px без роста и сжатия |

flex: 1 задают Flex-элементу, а не самому контейнеру. Элемент получает долю
свободного места внутри родителя.

#### Остальные свойства

| Свойство | Значения | Назначение |
|---|---|---|
| align-self | auto, stretch, flex-start, flex-end, center, baseline | переопределить align-items для одного элемента |
| order | целое число | изменить визуальную позицию; начальное 0 |
| margin-left: auto | auto | забрать свободное место слева и вытолкнуть элемент вправо |

order не меняет DOM-порядок, чтение скринридером и Tab-порядок. Поэтому им не
исправляют неправильную смысловую структуру.

### Типовые рецепты Flexbox

Равные ссылки навигации:

~~~css
.todo-nav {
  display: flex;
}

.todo-nav-link {
  flex: 1;
  text-align: center;
}
~~~

Кнопки справа:

~~~css
.todo-item {
  display: flex;
  align-items: center;
  gap: 8px;
}

.todo-actions {
  display: flex;
  gap: 8px;
  margin-left: auto;
}
~~~

Вертикальная страница, где main растягивается:

~~~css
.app {
  min-height: 100dvh;
  display: flex;
  flex-direction: column;
}

.app-main {
  flex: 1;
}
~~~

### Частые ошибки Flexbox

| Симптом | Причина |
|---|---|
| justify-content будто не работает | нет свободного места по главной оси |
| align-items двигает не туда | перепутаны главная и поперечная оси |
| длинный текст выталкивает кнопки | текстовому Flex-элементу нужен min-width: 0 |
| свойство flex ничего не делает | родитель элемента не Flex/Grid-контейнер |
| дочерний flex пропал после смены родителя | Flex-элементами являются только непосредственные дети |

## 9. Grid

Grid — двумерная раскладка по колонкам и строкам.

~~~css
.todo-item {
  display: grid;
  grid-template-columns: minmax(0, 1fr) auto;
  gap: 12px;
}
~~~

Первая колонка получает свободное место и может сжиматься, вторая имеет ширину
содержимого.

### Размеры дорожек

| Значение | Смысл |
|---|---|
| 200px | фиксированный размер |
| 30% | процент от контейнера |
| auto | размер по содержимому с возможностью занять место |
| 1fr | одна доля оставшегося пространства |
| min-content | минимальная ширина без лишних переносов слов |
| max-content | размер без переноса содержимого |
| minmax(0, 1fr) | от 0 до одной доли; хорошо для длинного текста |
| fit-content(300px) | по содержимому, но не больше указанной границы |

### repeat, auto-fit и auto-fill

~~~css
.cards {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
}

.responsive-cards {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));
  gap: 16px;
}
~~~

| Запись | Поведение |
|---|---|
| repeat(3, 1fr) | три одинаковые колонки |
| auto-fit | создать помещающиеся колонки и схлопнуть пустые |
| auto-fill | создать помещающиеся колонки, сохранив и пустые дорожки |

### Выравнивание Grid

| Свойство | На что действует |
|---|---|
| justify-items | элементы внутри их ячеек по строчной оси |
| align-items | элементы внутри ячеек по блочной оси |
| place-items | сокращение align-items и justify-items |
| justify-content | вся сетка внутри контейнера по строчной оси |
| align-content | вся сетка внутри контейнера по блочной оси |
| justify-self | один элемент по строчной оси |
| align-self | один элемент по блочной оси |
| place-self | сокращение align-self и justify-self |

Основные значения: start, end, center, stretch. У content-свойств также есть
space-between, space-around и space-evenly.

### Размещение элементов

| Свойство | Пример | Смысл |
|---|---|---|
| grid-column | 1 / 3 | от линии 1 до линии 3 |
| grid-column | span 2 | занять две колонки |
| grid-row | 2 | поместить во вторую строку |
| grid-area | header | назначить именованную область |
| grid-auto-flow | row, column, dense | направление автоматического размещения |

Grid удобен, когда несколько строк должны иметь одинаковые колонки. Flexbox
удобнее, когда важна одна строка или колонка и размер в основном зависит от
содержимого.

## 10. Position и z-index

### position

| Значение | Поведение |
|---|---|
| static | обычный поток; inset-свойства не двигают элемент |
| relative | остаётся в потоке; можно сместить относительно своего места |
| absolute | исключается из потока; позиционируется относительно ближайшего positioned-предка |
| fixed | исключается из потока; обычно привязан к viewport |
| sticky | ведёт себя обычно, пока не достигает указанной границы |

Positioned-предок — ближайший предок, у которого position не static.

~~~css
.card {
  position: relative;
}

.card-badge {
  position: absolute;
  inset-block-start: 8px;
  inset-inline-end: 8px;
}

.toolbar {
  position: sticky;
  top: 0;
}
~~~

### Координаты

| Физические свойства | Логические аналоги |
|---|---|
| top | inset-block-start |
| bottom | inset-block-end |
| left | inset-inline-start |
| right | inset-inline-end |
| inset | сокращение сразу для четырёх сторон |

Для sticky обязательно нужна граница, например top: 0. Поведение также зависит
от прокрутки и overflow предков.

### z-index

z-index задаёт порядок наложения, но сравнивается внутри stacking context —
контекста наложения. Новый контекст могут создать, например, positioned-элемент
с z-index, transform или opacity меньше 1. Огромное число z-index не позволяет
вырваться из контекста родителя.

## 12. Фон, рамка и тень

### Фон

| Свойство | Частые значения |
|---|---|
| background-color | цвет, transparent |
| background-image | url(...), linear-gradient(...) |
| background-repeat | repeat, no-repeat, repeat-x, repeat-y |
| background-position | center, top right, 50% 50% |
| background-size | auto, cover, contain, 100% 100% |
| background-attachment | scroll, fixed, local |

background — сокращение, но для читаемости не обязательно собирать всё в одну
строку.

### Рамка

~~~css
.card {
  border: 1px solid currentColor;
  border-radius: 8px;
}
~~~

| border-style | Вид |
|---|---|
| none | рамки нет |
| solid | сплошная |
| dashed | штриховая |
| dotted | точечная |
| double | двойная |

Можно задавать стороны отдельно: border-top, border-inline-start и другие.

### Тень и прозрачность

~~~css
.card {
  box-shadow: 0 4px 16px rgb(0 0 0 / 15%);
}
~~~

Порядок: смещение X, смещение Y, размытие, растяжение, цвет. Необязательное
слово inset рисует внутреннюю тень.

opacity: 0.5 делает полупрозрачным весь элемент вместе с детьми. Цвет с
альфа-каналом меняет прозрачность только конкретного фона, рамки или текста.

## 13. Псевдоклассы и псевдоэлементы

Псевдокласс выбирает существующий элемент по состоянию или положению.
Псевдоэлемент выбирает условную часть элемента или создаёт дополнительную
CSS-коробку.

### Псевдоклассы

| Псевдокласс | Когда подходит |
|---|---|
| :hover | указатель находится над элементом |
| :active | элемент прямо сейчас активируется, например зажата кнопка мыши |
| :focus | элемент имеет фокус любым способом |
| :focus-visible | браузер решил, что индикатор фокуса нужно показать |
| :focus-within | фокус имеет элемент или любой его потомок |
| :checked | checkbox/radio выбран |
| :disabled | form-control отключён атрибутом disabled |
| :enabled | form-control доступен |
| :required | поле обязательное |
| :valid, :invalid | результат встроенной HTML-валидации |
| :first-child | первый ребёнок родителя |
| :last-child | последний ребёнок |
| :nth-child(2n) | каждый чётный ребёнок |
| :empty | нет детей и текста |

hover не заменяет focus-visible: клавиатурный пользователь не наводит мышь.

~~~css
.button:not(:disabled):hover {
  background: var(--button-hover);
}

.button:focus-visible {
  outline: 3px solid var(--focus-color);
  outline-offset: 2px;
}
~~~

### Псевдоэлементы

| Псевдоэлемент | Что выбирает/создаёт |
|---|---|
| ::before | коробка перед содержимым |
| ::after | коробка после содержимого |
| ::placeholder | текст подсказки input |
| ::selection | выделенный пользователем текст |
| ::marker | маркер списка |
| ::first-letter | первая буква блочного текста |

Для ::before и ::after обычно нужно свойство content. Они не заменяют важный
HTML-контент: скринридер и копирование текста могут обрабатывать их иначе.

~~~css
.required-label::after {
  content: " *";
  color: red;
}
~~~

## 14. Формы, состояния и доступность

### Фокус

Не удаляй outline без равноценной замены. Хороший индикатор заметен и на светлом,
и на тёмном фоне.

~~~css
:where(a, button, input, select, textarea):focus-visible {
  outline: 3px solid var(--focus-color);
  outline-offset: 2px;
}
~~~

### disabled и визуальное отключение

Настоящий HTML-атрибут disabled:

- блокирует взаимодействие с form-control;
- убирает его из Tab-порядка;
- сообщает состояние вспомогательным технологиям;
- позволяет выбрать элемент через :disabled.

pointer-events: none только отключает события указателя. Это не замена disabled:
клавиатура и смысл элемента от него не меняются.

### Способы скрытия

| Способ | Занимает место | Обычно доступен скринридеру | Можно взаимодействовать |
|---|---:|---:|---:|
| display: none | нет | нет | нет |
| HTML hidden | нет | нет | нет |
| visibility: hidden | да | нет | нет |
| opacity: 0 | да | да | да |

opacity: 0 не скрывает элемент функционально. Невидимая активная кнопка — ошибка.

### Активная ссылка и фокус — разные состояния

NavLink может получить активный класс и aria-current="page", потому что её URL
совпадает с текущей страницей. :focus-visible появляется временно при
клавиатурном фокусе. Активность нужно показывать постоянно, а фокус — отдельно.

## 15. Адаптивность

Mobile first означает: базовые стили предназначены для узкого экрана, а
min-width media query добавляет раскладку для более широкого.

~~~css
.todo-item {
  display: grid;
  gap: 8px;
}

@media (min-width: 48rem) {
  .todo-item {
    grid-template-columns: minmax(0, 1fr) auto;
    align-items: center;
  }
}
~~~

Media query проверяет характеристики браузерной среды. React для этого не нужен.

### Частые media features

| Условие | Что проверяет |
|---|---|
| min-width: 48rem | viewport не уже значения |
| max-width: 48rem | viewport не шире значения |
| orientation: landscape | горизонтальная ориентация |
| hover: hover | основное устройство умеет удобный hover |
| pointer: coarse | основной указатель неточный, например палец |
| prefers-color-scheme: dark | пользователь предпочитает тёмную схему |
| prefers-reduced-motion: reduce | пользователь просит меньше анимации |

~~~css
@media (prefers-reduced-motion: reduce) {
  *,
  *::before,
  *::after {
    scroll-behavior: auto;
    animation-duration: 0.01ms;
    animation-iteration-count: 1;
    transition-duration: 0.01ms;
  }
}
~~~

Container query проверяет размер конкретного контейнера, а не окна:

~~~css
.todo-panel {
  container-type: inline-size;
}

@container (min-width: 32rem) {
  .todo-item {
    grid-template-columns: minmax(0, 1fr) auto;
  }
}
~~~

### Практические правила

- не делай весь интерфейс фиксированной ширины;
- используй max-width вместе с width: 100%;
- разрешай длинному тексту переноситься или обрезай его осознанно;
- проверяй увеличение текста, узкий экран и клавиатуру;
- breakpoint выбирай по моменту, когда ломается содержимое, а не по модели
  конкретного телефона.

## 16. Transform, transition и animation

### transform

| Функция | Действие |
|---|---|
| translate(x, y) | визуальное перемещение |
| translateX(x), translateY(y) | перемещение по одной оси |
| scale(n) | масштаб |
| rotate(angle) | поворот |
| skew(angle) | наклон |

transform меняет отрисовку, но обычно не перераскладывает соседей.

### transition

~~~css
.button {
  transition: background-color 150ms ease, transform 150ms ease;
}

.button:not(:disabled):active {
  transform: translateY(1px);
}
~~~

| Часть | Примеры |
|---|---|
| transition-property | color, opacity, transform |
| transition-duration | 150ms, 0.3s |
| transition-timing-function | linear, ease, ease-in, ease-out |
| transition-delay | 0s, 100ms |

Лучше перечислять свойства, чем писать transition: all. Иначе неожиданное
изменение любого свойства тоже начнёт анимироваться.

### animation

~~~css
@keyframes pulse {
  from { opacity: 0.5; }
  to { opacity: 1; }
}

.saving {
  animation: pulse 700ms ease-in-out infinite alternate;
}
~~~

| Свойство | Частые значения |
|---|---|
| animation-name | имя keyframes |
| animation-duration | 700ms |
| animation-timing-function | ease, linear |
| animation-delay | 0s |
| animation-iteration-count | 1, infinite |
| animation-direction | normal, reverse, alternate |
| animation-fill-mode | none, forwards, backwards, both |
| animation-play-state | running, paused |

## 17. CSS custom properties и функции

### CSS custom properties

Их часто называют CSS-переменными. Они существуют в браузере во время работы
страницы и наследуются.

~~~css
:root {
  --surface: #ffffff;
  --text: #202124;
  --space-md: 16px;
}

[data-theme="dark"] {
  --surface: #202124;
  --text: #ffffff;
}

.card {
  color: var(--text);
  background: var(--surface);
  padding: var(--space-md);
}
~~~

var поддерживает запасное значение:

~~~css
color: var(--unknown-color, black);
~~~

### Вычислительные функции

| Функция | Пример | Смысл |
|---|---|---|
| calc | calc(100% - 32px) | арифметика с совместимыми единицами |
| min | min(100%, 70rem) | выбрать меньшее |
| max | max(16px, 2vw) | выбрать большее |
| clamp | clamp(1rem, 2vw, 1.5rem) | минимум, гибкое значение, максимум |

~~~css
.page-title {
  font-size: clamp(1.5rem, 4vw, 2.5rem);
}
~~~

## 18. SCSS

Sass — Syntactically Awesome Style Sheets, «синтаксически улучшенные таблицы
стилей». Это препроцессор: его код преобразуется в обычный CSS до запуска в
браузере.

SCSS — Sassy CSS. Это основной синтаксис Sass с фигурными скобками и точками с
запятой, похожий на обычный CSS. Любой корректный современный CSS обычно
является корректным SCSS.

~~~text
index.scss → Sass compiler → CSS → Vite bundle → браузер
~~~

### Вложенность и &

~~~scss
.todo-item {
  padding: 8px;

  &:hover {
    background: #f5f5f5;
  }

  &.completed {
    opacity: 0.7;
  }

  &__title {
    min-width: 0;
  }
}
~~~

Компиляция даёт плоские селекторы:

~~~css
.todo-item:hover { ... }
.todo-item.completed { ... }
.todo-item__title { ... }
~~~

& означает текущий внешний селектор. Пробел перед вложенным селектором меняет
смысл:

~~~scss
.todo-item {
  .title { ... }   // потомок: .todo-item .title
  &.active { ... } // тот же элемент: .todo-item.active
}
~~~

Не стоит вкладывать селекторы на много уровней: итоговая специфичность растёт, а
компонент становится зависимым от точной DOM-структуры.

### Sass variables и CSS custom properties

| Sass variable | CSS custom property |
|---|---|
| записывается как $space | записывается как --space |
| существует при сборке | существует в браузере |
| после компиляции исчезает | остаётся в итоговом CSS |
| не меняется от data-theme во время работы | участвует в каскаде и наследуется |
| удобна для расчётов и генерации CSS | удобна для runtime-темы |

~~~scss
$space-md: 16px;

.card {
  padding: $space-md;
  color: var(--text-color);
}
~~~

### Mixins

Mixin — переиспользуемый набор объявлений.

~~~scss
@mixin focus-ring($color) {
  outline: 3px solid $color;
  outline-offset: 2px;
}

.button:focus-visible {
  @include focus-ring(var(--focus-color));
}
~~~

### Файлы и @use

Файл вроде _mixins.scss называется partial: он предназначен для подключения и
сам по себе обычно не создаёт отдельный CSS-файл.

~~~scss
@use "./mixins";

.button:focus-visible {
  @include mixins.focus-ring(var(--focus-color));
}
~~~

@use предпочтительнее старого @import: он создаёт явное пространство имён и не
сваливает все имена в одну глобальную область.

## 19. Global CSS, CSS Modules и CSS-in-JS

| Подход | Как работает | Плюсы | Ограничения |
|---|---|---|---|
| Global CSS/SCSS | классы глобальны для страницы | просто, удобно для reset, tokens и layout | возможны совпадения имён |
| CSS Modules | сборщик превращает локальные классы в уникальные | защита от совпадения классов, обычный CSS | файл должен называться .module.css или .module.scss |
| CSS-in-JS | стили описываются из JavaScript, часто библиотекой | удобно связывать с props и компонентами | дополнительная библиотека и runtime/build-time особенности |

### CSS Modules в Vite

~~~css
/* TodoContent.module.css */
.title {
  overflow: hidden;
}
~~~

~~~jsx
import styles from "./TodoContent.module.css";

export function TodoContent({ title }) {
  return <span className={styles.title}>{title}</span>;
}
~~~

Vite предоставляет обработку CSS Modules по соглашению об имени файла.
Обычный modules.scss не является модулем; нужен суффикс .module.scss.

### Что куда помещать

- reset, CSS custom properties темы, базовую типографику — в глобальные стили;
- стили конкретного небольшого компонента — в CSS Module;
- SCSS применим и глобально, и внутри Modules;
- CSS-in-JS нужен не автоматически, а когда команда выбрала такой подход и его
  динамика действительно полезна.

  min-height: 100dvh;
  display: grid;
  place-items: center;
}
~~~

### Равные пункты навигации

~~~css
.nav {
  display: flex;
}

.nav > a {
  flex: 1;
  padding: 12px;
  text-align: center;
}
~~~

### Текст слева, действия справа

Grid удобен, если группа действий должна образовывать отдельную колонку:

~~~css
.todo-item {
  display: grid;
  grid-template-columns: minmax(0, 1fr) auto;
  align-items: center;
  gap: 12px;
}

.todo-actions {
  display: flex;
  gap: 8px;
}
~~~

Внутренний display: flex у .todo-actions остаётся нужен: Grid размещает сам блок
действий, а Flexbox размещает кнопки внутри этого блока.

### Прижать один элемент вправо во Flexbox

~~~css
.row {
  display: flex;
  align-items: center;
}

.row-actions {
  margin-left: auto;
}
~~~

auto-margin забирает доступное свободное место с указанной стороны.

### Адаптивные карточки без media query

~~~css
.cards {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(min(240px, 100%), 1fr));
  gap: 16px;
}
~~~

### Страница 404 внутри растягивающегося layout

~~~css
.app-layout {
  min-height: 100dvh;
  display: flex;
  flex-direction: column;
}

.app-layout > main {
  flex: 1;
  display: flex;
}

.not-found-page {
  flex: 1;
}
~~~

Если вместо .not-found-page использовался Fragment, его h1, p и button были
непосредственными Flex-элементами main и по умолчанию растягивались через
align-items: stretch. После появления div непосредственным Flex-элементом стал
только div; его дети вернулись к обычному блочному потоку.

### Доступный focus ring

~~~css
:where(a, button, input, select, textarea):focus-visible {
  outline: 3px solid var(--focus-color);
  outline-offset: 3px;
}
~~~

## 21. Отладка CSS

### Порядок проверки

1. Выбери элемент во вкладке Elements.
2. Проверь, есть ли ожидаемый className в реальном DOM.
3. Найди правило во вкладке Styles.
4. Если объявление зачёркнуто — посмотри победившее правило и специфичность.
5. В Computed проверь итоговое вычисленное значение.
6. Проверь структуру родителей и непосредственных детей.
7. Для Flex/Grid включи визуальную подсветку раскладки в DevTools.
8. Проверь размеры, свободное место, overflow и min-width.
9. Проверь узкий экран, увеличение текста и клавиатурный фокус.

### Симптомы и вероятные причины

| Симптом | Сначала проверить |
|---|---|
| класс не действует | совпадает ли className с селектором, импортирован ли файл |
| свойство зачёркнуто | какое правило выиграло каскад |
| width больше ожидаемой | box-sizing, padding, border |
| margin auto не центрирует | есть ли ограниченная width/max-width и свободное место |
| justify-content не видно | есть ли свободное место по главной оси |
| align-items двигает не туда | какое значение flex-direction |
| кнопки ушли под заголовок | перенос, ширина, Grid-колонки и текущий DOM-родитель |
| многоточие не появляется | nowrap, overflow, ограничение ширины, min-width: 0 |
| sticky не работает | задан ли top, какой предок прокручивается, его overflow |
| z-index не помогает | разные stacking contexts |
| hover есть, а Tab не видно | отсутствует :focus-visible |
| правило из SCSS странное | посмотри скомпилированный селектор и положение & |
| CSS Module не локализует класс | имя файла не содержит .module |

## Главное помнить

- Сначала определи DOM-структуру, затем выбирай раскладку.
- Flexbox отвечает за одну ось, Grid — за строки и колонки.
- Свойства контейнера и его элементов — разные группы свойств.
- justify-content работает по главной оси, align-items — по поперечной.
- Каскад выбирает значение по важности, специфичности и порядку.
- Большинство текстовых свойств наследуется, размеры и box model — обычно нет.
- width: 100% и max-width решают разные задачи.
- CSS не должен скрывать смысл HTML: disabled, label, button и ссылка остаются
  семантическими HTML-механизмами.
- Любой интерактивный элемент проверяй мышью, Tab и при увеличенном тексте.
